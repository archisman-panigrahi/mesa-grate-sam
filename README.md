This is a patch generated by Sam Pavlovic that he shared on Open RT Discord, for enabling GPU acceleration in Surface RT.
This GitHub repo was created to build it for Debian armhf using GitHub Actions.

The `Build Mesa grate packages` workflow builds the patch as native `armhf`
Debian packages for Debian 12 (Bookworm) and Debian 13 (Trixie). It packages
the core Mesa libraries, the grate DRI driver, and their development files
under Debian package names. It does not rebuild the Vulkan, VA-API, VDPAU,
OpenCL, or OSMesa packages because this build enables none of those features.
Install the packages from one release's artifact together with `apt` so their
Mesa library versions stay matched. The release's optional Mesa packages may
be removed by `apt` if they require an exact version of the replaced libraries.

The build is pinned to the Mesa commit that the patch currently applies to.
When the patch no longer applies to a newer Mesa commit, update `MESA_REF` in
`.github/workflows/build.yml` only after checking the patch series against that
commit.
